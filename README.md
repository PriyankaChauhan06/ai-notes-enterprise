# AI Notes Enterprise

A full-stack AI-powered notes management application built with React, Node.js, TypeScript, MongoDB, Redis, and OpenAI.

## 🚀 Features

- User registration and login
- JWT-based authentication
- Access and refresh token authentication
- Google OAuth login
- Create, read, update and delete notes
- User-specific note ownership
- Input validation and error handling
- Redis integration
- AI-powered note features using OpenAI
- Responsive React frontend
- RESTful API architecture

## 🛠️ Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express
- TypeScript
- MongoDB
- Mongoose
- JWT
- Redis

### Authentication
- JWT Access & Refresh Tokens
- Google OAuth 2.0

### AI
- OpenAI API
